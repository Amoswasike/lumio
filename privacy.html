PRIVACY

Your financial information deserves clear privacy practices.

This page explains Lumio's current approach to personal information and financial records based on the V1 application's present architecture.

OVERVIEW

About this policy

Lumio Finance is a personal finance management application designed to help you understand, organize, and manage your money in one place.

Lumio brings income, expenses, budgets, financial goals, bills, notifications, search, and financial analytics into a single workspace.

This privacy information describes the current V1 application's approach to information and data. It should be reviewed and updated whenever the application's data architecture or third-party services change.

INFORMATION IN LUMIO

Information you provide to the application

Depending on how you use Lumio, the application may contain information associated with your account and financial activity.

  • Account information such as your name and email address.
  • Financial transaction information such as income, expenses, amounts, dates, categories, descriptions, and notes.
  • Budget information such as budget categories, budgeted amounts, spending, remaining amounts, and utilization.
  • Financial goal information such as goal names, target amounts, and progress.
  • Bill information such as amounts, categories, due dates, and payment status.
  • Application preferences such as currency, timezone, notification preferences, and theme settings.

USE OF INFORMATION

How Lumio uses information

Information within Lumio is used to provide the application's personal finance management functionality.

  • Provide access to your Lumio account.
  • Record and organize income and expenses.
  • Calculate and display financial summaries.
  • Manage budgets and budget utilization.
  • Track financial goals and progress.
  • Organize recurring and upcoming bills.
  • Provide notifications and application activity.
  • Support global search across supported financial records.
  • Provide dashboards and financial analytics.
  • Apply the preferences configured within the application.

CURRENT V1 DATA STORAGE

Where your financial data is stored today

The current Lumio V1 application uses a browser-based, client-side data architecture. Financial records are currently stored through browser storage on the device where the application is being used.

The current implementation does not represent a production cloud database architecture.

Because data is currently associated with browser-based storage, users should take appropriate care of the devices and browsers they use to access Lumio.

DATA OWNERSHIP

User-scoped financial information

Lumio's application architecture is designed around associating authenticated financial records with the relevant user account.

The V1 implementation has been tested with separate accounts using shared browser storage, with each account retaining its own financial data.

This behavior describes the current application implementation and should not be interpreted as a guarantee of the security infrastructure of a financial institution.

THIRD-PARTY SERVICES

External services

Any third-party service used by the Lumio website or application should be identified in the production version of this policy.

This may include services used for website hosting, application hosting, forms, analytics, authentication, error monitoring, or other infrastructure.

Lumio should not claim that information is or is not shared with a particular third party until the actual production integrations have been confirmed.

FINANCIAL CONNECTIONS

Lumio does not currently connect directly to your bank.

The current Lumio V1 application does not provide direct bank synchronization or automatic bank-account importing.

Financial information is currently recorded within the application rather than obtained through a direct bank connection.

SECURITY

Security should reflect the actual architecture.

Lumio uses validation, controlled application state, separated application responsibilities, and user-scoped financial records as part of its current application architecture.

The current V1 browser-based architecture should not be represented as providing the same security controls or infrastructure as a bank or financial institution.

Lumio intentionally avoids unsupported claims such as “bank-grade security” or “military-grade encryption.”

YOUR CONTROLS

Managing your information

Lumio provides application settings for managing supported account and experience preferences, including currency, timezone, notification preferences, and theme.

The current V1 browser-based architecture also means that browser and device-level data-management controls may affect locally stored application information.

A production account and data-deletion process should be documented here once the backend architecture and account-management workflows are implemented.

POLICY UPDATES

This policy will evolve with the product.

Lumio's privacy documentation should be updated when the product introduces new data-storage mechanisms, backend services, analytics, authentication systems, integrations, or other material changes to how information is handled.

Before a production launch, this document should be reviewed against the final technical implementation and applicable privacy requirements.

PRODUCT SCOPE

Lumio is a personal finance management application.

Lumio is designed to help you understand, organize, and manage your everyday finances.

Lumio is not a bank, investment platform, or financial institution.
