FREQUENTLY ASKED QUESTIONS

Questions about Lumio Finance?

Straightforward answers about Lumio, its features, and the capabilities of the current application.

What is Lumio Finance?

Lumio Finance is a personal finance management application designed to help you understand, organize, and manage your money in one place.

It brings income, expenses, budgets, financial goals, bills, notifications, search, and financial analytics into a single workspace.

Who is Lumio Finance for?

Lumio is designed for individuals managing everyday finances, professionals and employees tracking salary and recurring expenses, freelancers and side-hustle earners managing multiple income sources, and people working toward financial goals.

Can I track income and expenses?

Yes. Transactions are a core part of Lumio. You can record income and expenses with amounts, dates, categories, descriptions, and notes.

What can I use budgets for?

Lumio lets you create budgets for areas such as housing, food, transport, utilities, shopping, and healthcare.

You can monitor the budgeted amount, spending, remaining amount, and utilization. Budget spending is synchronized with relevant transactions.

Can I create financial goals?

Yes. You can create savings goals with target amounts and monitor your progress toward those targets.

Can I manage bills?

Yes. The Bills feature is designed to help you track recurring and upcoming bills, including amounts, categories, due dates, and payment status.

What financial information can I see on the dashboard?

Lumio's financial summary can include income, expenses, balance, savings, average income, average expense, largest income, largest expense, and savings rate.

What does Lumio analytics show?

Analytics provides deeper views of your recorded financial information, including cash flow, income composition, expense composition, savings trends, and budget performance.

Can I search my financial records?

Yes. Lumio includes global search across transactions, budgets, bills, and financial goals.

Does Lumio have notifications?

Yes. Lumio provides a centralized notification experience for relevant financial events and application activity.

Notification preferences can be managed through the application's settings.

Can I personalize Lumio?

Yes. Application settings include currency, timezone, notification preferences, and theme settings, including dark theme support.

Does Lumio connect directly to my bank?

Not in the current application architecture. Lumio currently does not provide direct bank synchronization.

The public website should not imply bank connectivity until that capability is implemented and verified.

Where is my financial data stored?

The current Lumio V1 application uses browser-based, client-side data storage. Financial records are currently stored through browser storage rather than a production cloud database.

The data-storage model will need to be updated on this page when a production backend architecture is implemented.

Is my financial information associated with my account?

Yes. The current application is designed around associating authenticated financial records with the relevant user account.

The V1 implementation has also been tested with separate accounts using shared browser storage, with each account retaining its own financial data.

Is Lumio a bank or financial institution?

No. Lumio is a personal finance management application. It is not a bank, investment platform, or financial institution.

Is Lumio available on mobile?

Lumio is designed as a responsive web experience that can be used across supported screen sizes.

A dedicated native mobile application should only be advertised if and when one is released.

Does Lumio provide bank-grade security?

Lumio does not make “bank-grade security” claims. The current V1 application uses a browser-based client-side architecture and should be described according to its actual capabilities.

Security documentation will evolve as the product's architecture develops.

How do I get started?

Create a Lumio account, add your income, record expenses, create budgets, add financial goals, add bills, and then use the dashboard and analytics to review your financial picture.
