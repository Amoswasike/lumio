01 — ABOUT LUMIO

Personal finance management

Lumio Finance is designed to help users understand, organize, and manage everyday financial information in one place.

The application provides functionality for tracking income and expenses, managing budgets, setting financial goals, managing bills, reviewing financial analytics, receiving notifications, searching financial records, and managing application preferences.

Lumio is not a bank, investment platform, financial institution, financial adviser, broker, lender, or other financial services institution.

03 — FINANCIAL INFORMATION

Information you enter into Lumio

Lumio allows users to record financial information including income, expenses, budgets, financial goals, and bills.

Users are responsible for the accuracy of the information they enter into the application.

Lumio's calculations, summaries, dashboards, and analytics are based on information recorded within the application.

Users should verify important financial information independently before making significant financial decisions.

04 — PRODUCT LIMITATIONS

What Lumio does not currently provide

The current V1 application has specific limitations.

  • Lumio does not currently provide direct bank synchronization.
  • Lumio does not currently provide automatic bank-account importing.
  • Lumio is not an investment platform.
  • Lumio is not a bank or financial institution.
  • Lumio does not provide personalized financial, investment, tax, accounting, or legal advice.

05 — CURRENT DATA ARCHITECTURE

Browser-based V1 architecture

The current Lumio V1 application uses a browser-based, client-side data architecture. Financial records are currently stored through browser storage on the device where the application is being used.

This architecture is different from a production cloud-backed financial service. Users should therefore not interpret Lumio as providing the infrastructure, availability, backup, or security controls associated with a bank or financial institution.

The application's terms and technical documentation should be updated when Lumio transitions to a production backend.
